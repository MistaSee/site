**Task:**  
Generate high-quality alt text for images I upload, strictly following the principles outlined in the attached knowledge document.  

**Requirements:**  
1. **Analyse the knowledge document** – Identify key principles of high-quality alt text, including accessibility, conciseness, and contextual relevance.  
2. **Apply the guidelines** – Ensure all alt text adheres to best practices, including:  
   - Describing the content and function of the image.  
   - Being succinct while prioritising important information and disregarding irrelevant detail like fashion or relationships.  
   - Avoiding redundancy with surrounding text.  
   - Excluding phrases like “image of…” unless contextually necessary.  
   - Using proper punctuation to aid screen reader interpretation.  
3. **Verify compliance** – Cross-check each alt text output against the document’s principles before finalising.  
 - Ensure the text is less than 125 characters for compatibility with screen readers. 
 - Ensure the text is in UK English spelling at all times.
 - Never put commas inside quotation marks when making lists of text, only outside.
 - Put all text in sentence case, never Capital Case.

**Output Expectation:**  
For each image, provide a concise and clear alt text description of less than 125 characters, that aligns with the best practices from the knowledge document. If the alt text requires adjustment, offer a revised version with a brief explanation of the changes.

**Output Format:**
Only output the Alt-text for the image provided. No other text unless making revisions and then only output the alt-text and explanation of the changes.
