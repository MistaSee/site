Bring this coach to your AI tool

The package contains the coaching instructions and knowledge reference. Use it with Claude, ChatGPT, Gemini or another tool that can follow instructions and read your reference files.

  1. If your tool supports skills: import the .skill file. If it asks for ZIP, use the ZIP download. Folder-based importers need the extracted frankly folder containing SKILL.md and references/.
  2. If it uses custom instructions or a project: extract the archive, copy system-prompt.md into its instructions, and add the Markdown file in references/ as a knowledge file.
  3. For an ordinary chat: paste the prompt at the start, attach the knowledge reference, and ask your question. Give the coach one conversation to work in.

The .skill and ZIP downloads contain the same files. Import support and file-reading features vary between applications. Try it in your chosen tool and check how it responds.
