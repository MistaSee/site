Bring this experiment to your AI tool

  1. Import a skill: use the .skill file, ZIP or extracted folder, as requested by your application.
  2. Use custom instructions or a project: copy system-prompt.md into the instructions and add any bundled reference files as knowledge.
  3. Use an ordinary chat: paste the prompt, attach the references and start a conversation.

Use the package with Claude, ChatGPT, Gemini or another tool that supports the necessary instructions, files and capabilities. The .skill and ZIP downloads contain the same files.
